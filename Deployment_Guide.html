cd "C:\Users\Cyrus\Desktop\Personal\2026\Calendar"

Step 1.2 — Create a new GitHub repository
  1. Go to github.com and sign in
  2. Click the + button → New repository
  3. Name it lowell-nails-calendar
  4. Set visibility to Private
  5. Do NOT check "Add README", "Add .gitignore", or "Choose a license" — keep it completely empty
  6. Click Create repository
Step 1.3 — Push your code

GitHub will show you the commands after creating the repo. Run these (replace the URL with your exact repo URL):

git remote add origin https://github.com/cyrusnguyen82/lowell-nails-calendar.git
git branch -M main
git push -u origin main
You should see "main" branch appear on github.com/cyrusnguyen82/lowell-nails-calendar
2
Create PostgreSQL Database on Render
This is the single database both Michael and the calendar share
Step 2.1 — Create the database
  1. Go to dashboard.render.com
  2. Click New + → PostgreSQL
  3. Fill in:
    FieldValue
    Namelowell-nails-db
    RegionOregon (US West) — match your existing service
    PlanFree
  4. Click Create Database and wait ~1 minute
Step 2.2 — Copy the connection string
  1. On the database info page, scroll to Connections
  2. Copy the Internal Database URL — it looks like:
    postgresql://lowell_nails_db_user:xxxxx@dpg-xxxxx-a/lowell_nails_db
  3. Save this URL — you will use it in the next phase
Use the Internal URL (not External) when both services are on Render — it's faster and free of egress charges.

Update michael-receptionist on Render
Push the new calendar API code and connect it to the database
Step 3.1 — Push updated code to GitHub

The michael-receptionist project now has new files (db.js, schema.sql, seed.js, routes/api.js) and an updated server.js. Push them:

cd "C:\Users\Cyrus\Desktop\michael-receptionist"
git add .
git commit -m "Add PostgreSQL calendar API routes"
git push
Render detects the push and starts redeploying automatically. This takes about 1–2 minutes.
Step 3.2 — Add environment variables on Render
  1. Go to your michael-receptionist service on the Render dashboard
  2. Click Environment in the left sidebar
  3. Add these variables (click Add Environment Variable for each):
KeyValue
DATABASE_URLPaste the Internal Database URL from Step 2.2
CORS_ORIGINLeave blank for now — you will fill this in after Phase 4

Click Save Changes — Render will redeploy automatically.

Step 3.3 — Create the tables and load seed data

Once the redeploy finishes (green dot next to the service name):

  1. On the michael-receptionist service page, click Shell in the left sidebar
  2. In the terminal that opens, run:
npm run db:setup
npm run db:seed

You should see:

✅ Database seeded successfully
   Technicians: Tina, Cyrus, Tianna, Dung, Van
   Clients: 10 records
   Appointments: 10 for today
   Login: admin/admin123  |  jane/staff123  |  tina/tech123  etc.
You only run this once. After this, all data is persisted in PostgreSQL and survives restarts.
4
Deploy Calendar Frontend on Render
Static site — always on, free, no spin-down
Step 4.1 — Create a Static Site on Render
  1. On the Render dashboard, click New + → Static Site
  2. Connect your GitHub account if prompted, then select lowell-nails-calendar
  3. Fill in the settings:
SettingValue
Namelowell-nails-calendar
Branchmain
Root Directoryfrontend
Build Commandnpm install && npm run build
Publish Directorydist
Step 4.2 — Add the API URL environment variable

Before clicking Create, scroll down to Environment Variables and add:

KeyValue
VITE_API_URLhttps://michael-receptionist.onrender.com
(use your exact Render URL for michael-receptionist)

Click Create Static Site. Render builds and deploys in ~2 minutes.

Step 4.3 — Save your live URL

After deployment, Render shows your URL at the top of the page:

https://lowell-nails-calendar.onrender.com
This URL works on any device, anywhere — phone, tablet, or computer.
5
Connect the Two Services
Allow the frontend to call the backend API
Step 5.1 — Update CORS on michael-receptionist
  1. Go back to the michael-receptionist service → Environment
  2. Find the CORS_ORIGIN variable and set it to your calendar URL:
https://lowell-nails-calendar.onrender.com
  1. Click Save Changes

Render redeploys in ~30 seconds. After that, both services are live and fully connected.

Step 5.2 — Test everything
  1. Open https://lowell-nails-calendar.onrender.com in your browser
  2. Sign in with admin / admin123
  3. Verify the calendar shows Tina, Cyrus, Tianna, Dung, and Van
  4. Book a test appointment → open on your phone → confirm it appears
  5. Test Michael by calling the Twilio number — he now has access to real booking data
If the calendar shows "Cannot connect to server" on first load, wait 30 seconds — the backend may be waking up from idle (free tier). Refresh and it will load.
